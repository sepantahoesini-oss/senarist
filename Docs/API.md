# API فعلی

- `GET /health` — وضعیت سرویس و اعلام اینکه پرداخت فعال نیست.
- `GET /api/catalog` — سه بستهٔ مجوز با قیمت به ریال.
- `GET /api/me` — فعلاً 501؛ احراز هویت هنوز پیاده‌سازی نشده.
- `POST /api/purchases/verify` — فعلاً 501 و fail-closed؛ رسیدی را تأیید نمی‌کند و مجوزی نمی‌افزاید.

این رفتار عمدی است. فعال‌کردن مسیر پرداخت بدون پیاده‌سازی اعتبارسنجی رسمی رسید مایکت ناامن است.
